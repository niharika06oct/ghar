# Archived exploratory prototypes

These three single-file HTML prototypes were early, standalone explorations that have been
**superseded** by the canonical app (`ghar-prototype.html` + the `server/` backend). They are
kept for reference only and are **not** served, deployed, or maintained.

- `Ghar.dc.html` — early cost-estimate explorer (built-up-area cost formula, city multipliers, vaastu).
- `Ghar Design.dc.html` — early shape/footprint design explorer (`shapeDefs`, capacity target, fit cards).
- `Ghar Estimate.dc.html` — early estimate view.

If any idea here is worth reviving (e.g. the cost model), port it into the canonical app rather
than reusing these files.
